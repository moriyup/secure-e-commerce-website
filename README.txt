3. Open XAMPP and click 'Start' for Apache and MySQL.

4. Create a database named 'epoch_story'. Then, import the epoch_story.sql file.

5. Open the laravel and click "Open the Herd dashboard".

6. Click 'General,' check the directory path, and open it

7. Copy and paste the Epoch_Story'. folder in the directory path.

8. Click 'Sites' and click tick the "HTTPS".

9. Then, click "Open in Browser".
  
9. Enjoy your system.
